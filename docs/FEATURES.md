# 機能一覧

ja-furigana が **何をするか** をまとめたもの。 内部の作りは [ARCHITECTURE.md](./ARCHITECTURE.md)、
辞書・ルールの書き方は [`ja-furigana-dict` の SCHEMA.md](https://github.com/RyuuNeko1107/ja-furigana-dict/blob/master/docs/SCHEMA.md)、
変更履歴は [CHANGELOG.md](../CHANGELOG.md)。

> 戻る: [README](../README.md)

読みの決まり方は 2 段構え:

1. **辞書・ルールに載っているものは確実に固定** (熟語・外来語・型番・数字の規則)
2. **載っていなければ形態素解析 (Lindera + IPADIC) の素直な結果に fall back**

すべて決定論 (同じ入力 → 同じ出力)。 機械学習の推論は実行時に使わない。

## 1. 出力モード

| `mode` | 出力 | 例 (`灰桜の散る道`) |
|---|---|---|
| `hiragana` | プレーンひらがな (ポーズなし。 漢字 → ひらがな、 英字・数字・記号の読みはカタカナ) | `はいざくらのちるみち` |
| `ruby` | `{漢字\|よみ}` 形式 | `{灰桜\|はいざくら}の{散る\|ちる}{道\|みち}` |
| `kanji` | 入力をそのまま返す (no-op) | `灰桜の散る道` |
| `tts` (default、 別名 `bouyomi`) | 読み上げ用。 句読点の間 (ポーズ) を整える。 `--silence-symbols` で絵文字・顔文字を外す | `はいざくらのちるみち` |
| `accent` | アクセント付きの JSON (アクセント句・モーラ・型) | `{"schema_version": "1", …}` |
| `voicevox-aques` / `aquestalk` | VOICEVOX / AquesTalk のアクセント記号列 | `ハイザクラノ'/チル'/ミチ'` |
| `romaji` / `romaji-kunrei` | ローマ字 (ヘボン式 / 訓令式) | `haizakuranochirumichi` / `haizakuranotirumiti` |
| `analyze` | 候補・採用 path・各 band を JSON で | デバッグ用 |

CLI (`furigana lookup`)、 HTTP サーバー (`furigana serve`)、 Rust lib (`Furigana::to_*`) のどれからでも同じ結果。
`ja-furigana-voicevox` / `ja-furigana-aquestalk` crate は各エンジンへ渡す adapter。

## 2. 漢字の読み

- **熟語辞書** (約 3.9 万) と **単漢字辞書** (約 4.3 万)。 辞書に載った語は確実に固定
- **文脈で読みを変える** (`[[match]]`): 直前・直後の文字、 次がひらがな / 漢字、 入力文全体に含まれる語 (話題で分岐)
- **単漢字の `[[kanji]]` ブロック**: 1 字の default の読みと文脈分岐 (例: `米` = 次がひらがななら こめ、 漢字なら ベイ)
- **人名**: 「名前 + さん / くん」 が活用形に割られるのを組み直す。 姓 + 敬称の suffix match
- **連濁・促音便**: 接尾辞の連濁形 (お疲れ = おづかれ)、 促音便の誤爆止め (七章 = しちしょう)
- **踊り字**: `々` の連濁 (`山々` = やまやま)
- **送り仮名**: 活用語尾を含む語の読み。 辞書語が形態素解析の 「漢字 1 字 + 助詞」 に割られるのを組み直す
- **アクセント**: 辞書の bracket 記法 → アクセント専用の表 (UniDic 由来、 12.8 万件) → 動詞・形容詞の活用は規則で推定

## 3. 数字・日時・単位

| 種類 | 例 |
|---|---|
| 助数詞 (連濁・促音) | `3本` = さんぼん / `5匹` = ごひき / 概数 `二三件` = さんけん |
| 大数 | `1万円` = いちまんえん / `3億2000万` |
| 位取りの漢数字 | `三五号` / `昭和四六年` / 法令の金額表記 `一、〇〇〇円` |
| 日付・時刻 | `2025年10月30日` / `午後零時三分` / `12:30` = じゅうにじさんじゅっぷん / `10:00` = じゅうじ |
| 範囲 | `10〜20人` = じゅうからにじゅうにん / `9時-17時` / `A〜Z` = エーからゼット |
| 比・スコア | `1:1` = いちたいいち / `50:50` |
| `N/M` | 手がかりが無ければ日付 (`10/12` = じゅうがつじゅうににち)、 分子 1 の `1/2`〜`1/10` は分数 (`1/3` = さんぶんのいち)。 分数の手がかり (`3/4くらい` / `HP 12/25`) は日付より先、 日付の手がかり (`1/3(日)` / `19:00` / `6/26〜7/2`) は分数寄りの組も日付に。 日付にならない組 (`13/5`) は分数、 `50/50` `24/7` `No.19/20` は読まない |
| 年付きの日付 | `2025/10/13` / `2000-10-12` = にせんにじゅうごねんじゅうがつじゅうさんにち (年 4 桁 + 月日が正しい形、 区切りは同じ) |
| 単位 (SI・通貨・%) | `100km` / `30fps` / `25℃` / `60km/h` = ロクジュッキロメートルマイジ / `3000rpm` |
| 通貨記号 | `¥1000` = せんえん / `$100` = ひゃくどる |
| バージョン・IP | `1.2.3` = いちてんにてんさん / `192.168.0.1` |
| 郵便番号 | `〒100-0001` / `郵便番号 100-0001` = ゆうびんばんごう イチゼロゼロ の ゼロゼロゼロイチ (`〒` か 「郵便番号」 が無い `100-0001` は読まない) |
| 深夜の時刻 | `25:00` = にじゅうごじ (0〜29 時) |
| 年付きのドット日付 | `2026.10.12` = にせんにじゅうろくねんじゅうがつじゅうににち (19xx / 20xx。 英字の直後は版) |
| 分数の文字 | `½` `¾` `⅓` は常に分数 |
| 累乗 | `10²` / `x^2` / `2^10` = じゅうのにじょう / エックスのにじょう (上付き数字は数字・英字・閉じ括弧の直後だけ) |
| 倍率 | `2x` / `1.5x` = にばい / `x2` = ニバイ (`0x1F` `2x2` `x86` `x64` は除く) |
| 版 `v2.0` | ブイ + 数 (`v1.2.3` も) |
| 範囲の `-` | `9:00-17:00` / `2024-2025` / `10-20人` = から (電話番号・型番のように前後に数字や英字が続く形は除く) |
| 拍手・対戦 | `888` = パチパチパチ / `1v1` = いちブイいち |
| 丸数字 | `①番` = いちばん、 連続 `①②③` = いち に さん |
| ローマ数字 | `Ⅱ世` / `第Ⅲ期` / `ドラクエⅤ` (Ⅰ〜Ⅻ はアラビア数字として読む) |
| 電話番号 | `090-1234-5678` = 1 桁ずつ (ゼロキュウゼロ イチニサンヨン …)。 国内は 10〜11 桁、 国際 `+81-90-…` / `+1 555-…` は 8〜15 桁 |
| 英字語 + 数字 | `Windows11` = ウィンドウズイレブン / `iPhone15` = アイフォンジュウゴ / `RTX4090` = アールティーエックスヨンゼロキュウゼロ (語ごとに読み方を `[digits]` で宣言) |
| 型番 | `Ryzen 7 5800X3D` / `i9-13900K` / `RTX 4070 Ti` / `iPhone 15 Pro Max` / `PS5` / `DDR5-6000` / `PCIe 5.0` / `GPT-4o` (`models.toml` に正規表現 + 雛形) |

## 4. 英字・外来語

- **外来語表** (`core/loanwords/`, 約 3,300 語): `Kubernetes` = クバネティス のように英字語を完全一致で読む。 大文字小文字・全角半角は同一視
- **複数語**: 空白でつながった英語は、 全部の語が表にあれば語ごとに読む (`Hello World` = ハロー ワールド)。 型番の前の語 (`Intel Core i7-…`) は表にある語だけ読む。 一部しか知らない英文 (`thank you very much`) は英字のまま
- **英文の中だけで使う語** (`[sentence_words]`: a / is / to / you …): 単独では引かない (日本語の中の `to` を壊さない) が、 英文の 1 語として読む (`thank you so much` = サンク ユー ソー マッチ)
- **連結した英語** (`thankyou` / `iloveyou` / `GameOver`): 辞書の語に区切れるときだけ読む。 略語・数字まじり・短いものは対象外
- **単独の `w`**: 笑い (`ゆっくりw` = ゆっくりワラ)。 直後が助詞なら文字名 (`キーwを押す` = キーダブリューをおす)。 式の中 (`w=2`) も文字名
- **英字の記号込み語**: `C++` / `C#` / `Wi-Fi` / `Node.js`
- **読まないもの**: URL・メール・絵文字 (保護トークンとしてそのまま)。 括弧の顔文字 (`(´・ω・`)`) は読みを空にして除外

## 5. 記号

`+` `-` `%` `〜` `・` `※` などは 1 文字読みの表 (`symbols.toml`) と文脈規則で処理する:
`×` は数字・英字・括弧の間 (`2×3` / `A×B`) なら かける、 それ以外 (`返事は×です`) は ばつ。
図形記号は伏せ字の書き方なら読む: `○ △ □ ◎` は常に (`○○さん` = まるまるさん)、 `● ■ ▲ ▼ ◆ ◇` はちょうど 2 つ並ぶか直後が敬称 (さん / 様 …) の時だけ。 装飾の `★★★` や 1 個だけの `■` は読まない。
半角カタカナ (`ｱﾘｶﾞﾄｳ`) は hiragana / tts 出力で読み (ありがとう) にする。
絵文字は辞書 (`rules/text/emoji.toml`) で読みを持てる: 装飾 (`♪` `☆`) は読まず、 名詞として使われた絵文字 (`🥚を産む` = たまごをうむ / `今日は🍜が食べたい`) だけ読む。 `アイス🍨楽しみー` や `ラーメン🍜が` のような装飾は読まない。 顔文字 (`( ^ω^)` `ε=ε=(ノ≧∇≦)ノ`) は読みを空にして除外。
`〜` は数字の間なら 「から」、 語尾の `〜` は読まない。 `-` は 「3-1」 のような区切りなら読まない、 負数なら 「マイナス」。
tts では英数字にはさまれた `.` `?` は文の区切りにしない (`example.com`)。

## 6. 辞書・ルールの種類

| 種類 | 場所 (`ja-furigana-dict`) | 役割 |
|---|---|---|
| `jukugo` | `core/jukugo/` | 熟語 (ジャンル別) |
| `unihan` | `core/unihan/` | 単漢字 fallback |
| `kanji` | `core/kanji/` | 単漢字の default + 文脈分岐 |
| `works` | `core/works/` | 作品・固有名詞 |
| `loanwords` | `core/loanwords/` | 外来語 `[entries]` / 英字 + 数字 `[digits]` / 英文の語 `[sentence_words]` |
| `accent` | `core/accent/` | アクセント専用の表 |
| `counters` `scales` `days` `numeric_phrases` | `rules/numbers/` | 助数詞・大数・日付・慣用句 |
| `units` `symbols` `models` `postprocess` | `rules/text/` | 単位・記号・型番・出力後の置換 |
| `context_cues` | `rules/text/context_cues.toml` | `N/M` が日付か分数かを決める手がかりの語 (直後 / 直前 / 文中)。 lib の組み込みに足される |
| `compat` | `rules/compat.toml` | 異体字の正規化 |

辞書は毎日自動でリリースされ (CalVer `vYYYY.MM.DD`)、 サーバーは `--auto-pull` / `[auto_update]` で取り込む。
分野ごとに辞書を外すこともできる (`exclude_dict_path` / `--exclude-dict`)。

## 7. 運用向け

- **辞書の穴の抽出**: `extract_dict_gap_candidates` で辞書にない漢字 token を context つきで取り出す (lib は telemetry を持たない)
- **hot reload**: 辞書を差し替えても再起動不要 (サーバー)
- **性能**: 1 万行/秒以上。 辞書は先頭 2 文字で区間を絞って引く
- **品質ゲート**: 回帰 corpus (約 1.2 万 case)、 mutation test、 diff coverage、 license / security audit を CI で必須化
- **互換**: 0.x のため minor version で破壊的変更がありうる ([MIGRATION.md](../MIGRATION.md))
